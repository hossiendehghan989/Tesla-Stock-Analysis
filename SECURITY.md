# Security and Data Policy

This repository is an educational research artifact. It must not contain credentials, private datasets, personal data, or trading instructions.

Please do **not** disclose security-sensitive details in a public issue. Use GitHub's private vulnerability reporting / Security Advisories when available, or contact the maintainer through [the profile](https://github.com/hossiendehghan989).

Historical results are not financial advice and should not be used as a live trading system.
