# Tesla Stock Analysis

A notebook-based data-science project for exploring Tesla stock behavior through technical indicators, machine-learning forecasting and sentiment signals.

## Scope

- Historical Tesla price analysis for 2015–2020
- Technical and social features
- XGBoost and LSTM forecasting experiments
- Sentiment-analysis workflow and visualization
- Reproducible notebooks for exploration and model development

## Contents

- `Hossein_Dehghan_Tesla_Stock_Prediction_XGBoost_LSTM.ipynb` — forecasting experiments
- `tesla_stock_analysis_Hossein_Dehghan_.ipynb` — exploratory stock analysis
- `colab_sentiment_code.ipynb` — sentiment-analysis workflow
- `recreate_sentiment_plot.py` — plot recreation utility

## Getting Started

Open the notebooks in Jupyter or Google Colab and run the cells in order. Install the dependencies required by each notebook before execution.

## Important Note

This is an educational and analytical project, not financial advice. Historical performance and model predictions do not guarantee future results.
